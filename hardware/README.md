# hardware/

**Status: empty scaffold.** Reserved for physical design files, complementing the schematics/photos already in `docs/schem/` and the datasheets/circuit docs in `docs/datasheets/` and `docs/`.

## Subdirectories 

- `schematics/` — circuit schematics (source files, e.g. KiCad/Eagle) for the perfboard build and the eventual custom PCB (Phase 4 in the root README roadmap)
- `pcb/` — PCB layout/gerbers, once the 5×7cm perfboard prototype gets migrated to a custom board
- `3d-models/` — enclosure/HANS box and balaclava mounting designs
